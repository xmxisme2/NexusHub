# 验收与测试计划

证明摘要回归：题库与详情的 USER/BOT 胜方一致；无证明返回 UNKNOWN/null；不同版本、规则、引擎或完整局面不得复用证明；失败、取消、删除及 UNKNOWN 结果不得显示必胜，后续 UNKNOWN 不覆盖已有 PROVEN。

| 类别 | 必测内容 | 通过条件 |
|---|---|---|
| 规则单测 | 15 种牌型、飞机翼牌、炸弹/王炸、顺子边界、PASS、终局 | 合法/非法和规范化结果稳定 |
| 状态性质 | 牌数守恒、座位轮转、两次 PASS 清墩、终局不可行动 | 随机合法状态无负牌/越权 |
| 求解一致性 | 小状态无剪枝 vs 优化、缓存开关、USER/BOT 轮流和 PASS | 结论完全一致 |
| 证明验证 | 获胜方边覆盖、失败方全应对、叶节点终局、非法边 | verifier 拒绝单主线伪证明 |
| API 契约 | OpenAPI schema、状态码、ID/时间、字段错误、幂等 | 契约测试与实现一致 |
| 权限 | 草稿/对局/任务对象范围、角色、停用会话、发布 | 越权统一 404/403，不能靠前端绕过 |
| 并发恢复 | 重复提交、过期版本、取消、租约过期、重启 | 只产生一次行动；旧 Worker 无法覆盖 |
| 前端 | 加载/空/失败、响应式、未知状态、焦点和错误回显 | 390/768/1440 宽度无阻断操作 |
| 门户卡片入口 | 点击斗地主和 OpsDesk 卡片、鼠标悬停、Tab 聚焦、Enter 激活、外链新标签页 | 整张卡片可进入；Hero 信息切换到对应系统；卡片高亮放大；OpsDesk 使用配置的 HTTPS 地址并保留 noopener/noreferrer |
| 交换先后手 | 创建对局勾选交换、双方手牌和先手互换、原残局不变 | 本局快照交换成功，机器人获得原 USER 手牌并按新先手运行；未勾选时行为与原来一致 |
| 残局卡片导航 | 点击标题/手牌/留白、Tab 聚焦和 Enter 打开 | 整卡进入对应详情，无独立“查看局面”按钮，无嵌套交互控件 |
| 残局详情发布 | 箭头返回、管理员发布、普通用户权限提示、重复点击、冲突/失败刷新 | 返回残局库；发布后显示已发布且隐藏发布按钮；失败保留可重试入口 |
| 已证明策略展示 | PROVEN/UNKNOWN、用户/机器人胜方、独立可滚动推演页、最多 5 条路线、游客读取和牌面文本 | 仅严格 PROVEN 显示策略与胜方；牌面按点数数量还原为可读牌面；UNKNOWN 不显示必胜出牌；每条路线标出轮到的座位，明确代表路线不替代全量证明 |
| 初版资源保护 | 小牌量残局、超时/节点上限、取消 | 能返回 UNKNOWN 并释放任务；初版不做性能指标展示和复杂基准 |

当前自动化检查：`python doc/tooling/generate_contracts.py`、`python doc/tooling/validate_contracts.py`、`python doc/tooling/validate_database.py`、Markdown 链接检查；CI 另使用 MySQL 8.4 空库执行 schema/seed。工程检查为 `mvn -B -ntp -f backend/pom.xml clean test`、`npm ci && npm run typecheck && npm run build`。
