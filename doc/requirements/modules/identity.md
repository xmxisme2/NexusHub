# 账号与公共基础模块

| 编号 | 需求 | 验收 |
|---|---|---|
| IAM-01 | 用户名密码登录，Cookie 会话，退出 | 登录轮换会话 ID；退出失效会话 |
| IAM-02 | 当前用户返回角色、权限码 | 菜单与服务端授权一致 |
| IAM-03 | 管理员创建普通账号或管理员账号 | 用户名唯一，不存明文密码 |
| IAM-04 | 管理员启停账号 | 停用会话立即失效，不能停用自身和最后启用管理员 |
| IAM-05 | 管理员重置密码 | 重置后全部旧会话失效，密码不写审计 |

首个管理员由部署命令从环境/交互输入创建，不提供匿名初始化 HTTP 接口，不在 SQL 写默认密码。首版无公开注册、邮箱找回、短信和验证码系统。

用户名 3～64 个小写字母/数字/点/下划线/短横线，以字母或数字开头；统一去首尾空白并小写。新建账号和重置密码要求 12～64 字符、UTF-8 字节最多 72，使用 Spring Security BCrypt（参数通过基准选择）。本地测试初始化账号由种子配置提供；生产初始化必须使用部署命令生成强密码。登录失败统一文案，按账户与来源限流。

会话空闲超时初值 30 分钟；首版单实例内存会话，重启重新登录。CSRF Token 通过专用 GET 获取，登录、退出后重新获取；所有 POST 包括登录需带 Token。凭证错误 401，不泄漏账号存在性。

数据：sys_user；API：[identity](../../api/identity.md)。
