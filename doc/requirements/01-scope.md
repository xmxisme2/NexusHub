# 项目范围

## 产品目标

NexusHub 提供统一卡片式系统工作台。当前开发优先聚焦斗地主残局实验室；OpsDesk 延后，不进入当前开发闭环。主要用户为登录的个人/小团队用户，不建立企业多租户体系。

## 首版闭环

登录 → 斗地主残局库 → 创建并校验两人残局 → 保存版本 → 用户/机器人按可配置先后手对弈或后台分析 → 查看胜负证明及分支 → 对局复盘。管理员和 OpsDesk 入口配置暂不进入当前迭代。

## 固定边界

- 两人独立对抗，取消地主/农民角色；参与者固定为 USER 与 BOT，谁先出完自己的手牌谁获胜。
- 两名参与者完全明牌；先手第一次必须出牌，之后双方均可选择不出。
- 先手最多 20 张，后手最多 17 张，均不能为空；同点数牌最多 4 张；用户为先手或后手可配置。
- 标准斗地主牌型保留但固定不包含四带二；门户首页保留，首张卡片进入斗地主残局系统。
- 无叫分、发牌、积分交易、真人联网、暗牌求解、赛事排名。
- 不引入大模型推断胜负，不将估计分数称为胜率。
- OpsDesk 采用独立外链入口 `https://www.xmxisme.com/opsdesk/`；本系统不代理其业务、不共享会话或令牌，统一入口管理和 SSO 仍延后。本阶段完整实现登录、残局发布和版本权限。
- 只提供一种规则版本，规则变更走版本升级，不提供任意组合开关。

## 交付层次

此次交付包括规范、需求、接口、DDL、架构、测试计划、开发计划和真实 Figma 设计。应用工程、执行数据库迁移、真实 OpsDesk 联通与性能测试属于后续实现阶段。

## 可调整假设

默认受邀账号、中文界面、浅色主题、桌面优先、移动端可访问。部署硬件、实际并发和 OpsDesk URL 尚未提供，参数采用可配置起点；这些不阻碍工程和规则开发。
